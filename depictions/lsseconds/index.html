LSSeconds

Add seconds to the lock-screen clock and status-bar time without replacing the system date.

Highlights

  • Supports iOS 17 status-bar time views and retains the legacy path.
  • Changes only the lock-screen clock; the date and subtitle remain intact.
  • Provides lock-screen, status-bar, and status-bar AM/PM settings.
  • Intentionally pauses and hides seconds during AOD, then resynchronizes on wake.

Compatibility

Tested on iOS 17.3.1 with RootHide. The rootless package layout and build are verified, but rootless runtime testing is not confirmed.
